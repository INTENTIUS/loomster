[Loom](https://github.com/awslabs/loom) is AWS Labs' application for building,
deploying and governing agents on Bedrock AgentCore. loomster deploys Loom
v1.9.0 as six CloudFormation stacks written in [chant](/loomster/concepts/glossary/#chant),
in three [tiers](/loomster/concepts/tiers-and-instances/), with the backup,
restore, upgrade, rotation and drift [Ops](/loomster/reference/ops/) to run it.

## Status

Every tier deploys end to end on [Floci](/loomster/concepts/glossary/#floci) and
on a real AWS account, and Loom's own API has deployed an agent to `READY` as
loomster's backend role.

| Tier | Floci | Real AWS |
|---|---|---|
| `light` | all stacks, local app with a real login | deployed, served, an agent deployed through Loom's API |
| `production` | all stacks and tier resources | all stacks over HTTPS, assistant `READY`, screens validated through MFA Cognito |
| `production-ha` | all stacks, Multi-AZ requested | all stacks, Multi-AZ and rotation live, beside a second instance |

[Validation](/loomster/reference/validation/) has the details, the recorded
claims, and what no run has shown.
