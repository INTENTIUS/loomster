# Run Loom on your laptop

This guide lives in the docs site, kept as the single source:

**https://intentius.io/loomster/guides/local/**

`just local-up` — a browsable Loom against Floci, no AWS account. You log in
through the frontend against Floci's Cognito (local admin `loom-admin`, password
printed by local-up), via a small Loom patch in `scripts/loom-patches/`.
What's real, what's patched, and how the local run is wired.
